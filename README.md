# Rusted Rhythms 🎶
A VR music sandbox game where players can create rhythms by interacting with objects in an abandoned factory.  
Built with **Unity 2022.3 LTS + XR Interaction Toolkit**.

## Demo
🎥 [Watch on YouTube](https://youtube.com/demo-link)  
![screenshot](docs/screenshot1.png)

## Features
- Immersive VR interaction (grab, throw, hit)
- Steam Audio for realistic 3D sound
- Layered rhythmic loops for music creation
- Hand-attached menu for settings & controls
- Teleportation & continuous movement support

## Controls
- 🎮 Left Joystick → Movement / Teleport
- 🎮 Right Trigger → Grab / Hit objects
- 🎮 Left Menu Button → Open Hand Menu

## Tech Stack
- Unity 2022.3 LTS
- XR Interaction Toolkit (OpenXR)
- Steam Audio
- C#, Shader Graph
